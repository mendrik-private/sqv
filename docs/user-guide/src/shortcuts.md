# Keyboard and mouse reference

Press `?` in sqview for help. `Ctrl-P` opens the command palette, which includes
commands such as export, copying as CSV or SQL, global search, restoring hidden
columns, freezing the first column, reloading schema, and toggling read-only.

Keys depend on focus. For example, `i` inserts a row in the grid and shows schema
in the sidebar. `j` follows a foreign-key link when one is focused; `↓` always
moves down. In the SQL console, `Ctrl-P` recalls a statement from history.
